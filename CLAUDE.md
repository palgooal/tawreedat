## Design Context

This project uses [Impeccable](.claude/skills/impeccable/SKILL.md) for frontend design work. Full strategic context (register, users, brand personality, anti-references, design principles, accessibility target) lives in [`PRODUCT.md`](PRODUCT.md) at the project root — read it before any UI/design task.

Quick summary: Tawreedat (توريد) is a **brand-register** directory/guide of building-materials factories, contractors, and suppliers in Saudi Arabia. Personality: trustworthy, official, professional (Gov Green + Gold palette). Explicitly avoid generic AI-SaaS template looks, dull bureaucratic government-site flatness, and flashy consumer-marketplace clutter. RTL-first (Arabic), WCAG 2.1 AA target.

See also [`docs/DESIGN_SYSTEM.md`](docs/DESIGN_SYSTEM.md) for the current implemented visual system (colors, typography, components, layout rules).
